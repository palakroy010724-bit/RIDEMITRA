# RideMitra 🚗 Ride-Sharing Platform

RideMitra is a web application designed to seamlessly connect drivers and ride-seekers, offering dedicated dashboards and profile management for both user types.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS
